### 01.02 — Run jobs with leases and safe recovery

**Files:** `packages/server/src/jobs/queue.ts`, `packages/server/src/jobs/runner.ts`, `packages/server/src/jobs/kinds.ts`, `packages/server/src/worker.ts`, `packages/server/test/integration/jobs.test.ts`.

**Depends on:** 01.01 and phase prerequisites.

**Interface and implementation contract:** enqueue(tx: Transaction, job: JobSpec): Promise<void>; claimJob(db: Database, workerId: string, leaseSec: number): Promise<LeasedJob|null>. SKIP LOCKED, bounded attempts/backoff, owner/lease token and heartbeat for long work. Inline and separate worker modes share handlers; only the current lease owner can complete a job.

**Review completion contract:** A dedupe key must identify an occurrence, not suppress future legitimate work forever. Reconciliation reschedules failed/stalled work with a fresh scan identity.
