### 04.01 — Store identity-bound contributor payout details

**Files:** `packages/server/src/http/connect.ts`, `packages/server/src/actions/connect.ts`, `packages/server/src/db/migrations/0005_contributors.sql`, `packages/server/test/integration/connect.test.ts`.

**Depends on:** Phase prerequisites and shared types from Phase 00.

**Interface and implementation contract:** connectContributor(ctx: ActorContext,input: {paypalEmail:string}): Promise<ActionResult<Contributor>>. GitHub ID comes from the session; validate email, require CSRF and encrypt stored payment email using versioned application encryption.
