# Phase 12: MVP acceptance, documentation and demo

> **For agentic workers:** Implement task-by-task when authorized, following repository AGENTS.md and the contracts below. Optional skills are not prerequisites; do not assume uninstalled skills exist. This plan does not authorize execution.

**Status:** Local handoff tooling and documentation implemented; verification recorded in [Phase 12 summary](../evidence/12-summary.md). Full acceptance, hosted/live checks and recording remain pending by user direction.

**Goal:** Deliver a reviewable MVP whose claimed features, setup instructions and demo match verified behavior.

**Architecture:** GitHub-first workflows; authoritative Postgres state and durable jobs; authenticated financial actions; external calls outside transactions. Reuse the approved domain and provider boundaries instead of introducing parallel state machines.

**Tech stack:** TypeScript strict, Node 22, pnpm, Express, PostgreSQL 16/Drizzle, Zod, Vitest; GitHub/PayPal/Copilot SDK and web tooling only where this phase needs them.

**Spec:** [Implementation plan](../../IMPLEMENTATION_PLAN.md), [cancellation decision](../decisions/0001-open-participation-and-cancellation.md), and [MVP review index](README.md).

**Prerequisites:** [Phase 11](11.md)

**Scope:** Complete acceptance matrix, fresh-clone setup, Postman/demo fixtures and a clear demo. Sponsor extras remain outside completion criteria unless explicitly approved.
